# Retrospective

Read [workflow](../workflow/SKILL.md) and [writing-for-agents](../writing-for-agents/SKILL.md). Read the specified session's available evidence, or the current session when none is specified.

Investigate navigation friction, missing automated checks, confusing standards, unnecessary instructions, expensive repeated retrieval and missing access to needed information. Link each proposed improvement to an observed occurrence. Project standards apply during implementation and review; assess whether their instructions are discoverable at both points.

Present ranked improvements with the evidence, intended behavioral result and affected files or capabilities. Keep advice separate from authorization to apply it. Finish with actionable proposals rather than speculative rules or automatic changes to global instructions.
