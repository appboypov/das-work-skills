# Research

Read [workflow](../workflow/SKILL.md). Define the question and what evidence would answer it. Read relevant project context and existing findings first.

Investigate official documentation, source code, specifications or first-party data. Trace material claims to the source that owns them, recording version or date where behavior changes across releases. Resolve contradictions with direct source or runtime evidence when accessible. Distinguish observed facts, inferences and unresolved points.

Save one cited findings document in the selected change or the project's established research location. Include the answer, evidence, implications for the requested outcome and unresolved prerequisites. Link it from the change and comment on related Linear work only when its findings matter there. Research runs directly; optional concurrency follows the shared workflow's execution rules.
