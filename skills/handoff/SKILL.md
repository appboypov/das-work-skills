# Handoff

Read [workflow](../workflow/SKILL.md). Identify what the next session must accomplish and save a handoff in the selected change or a portable location the recipient can access.

Record the approved scope, owning intent path, defining `.das-work` path, exact working directories, selected store, change identity and path, Linear links, current task frontier, unresolved decisions and evidence references. Preserve the intent and folder ownership through [intent context](../workflow/SKILL.md#intent-context). For incomplete archive ingestion, carry the archived identity, saved brain paths and remaining work from its evidence. State what was actually checked, what failed and what has not run. Include applicable skill links and the next bounded action.

Link existing specs, design, source and reports rather than copying them. Redact credentials, tokens and personal data not needed by the recipient. Verify referenced files exist and the recipient can identify the starting directory. Return the handoff location and what it enables. Starting a session uses whichever mechanism the recipient's host provides.
