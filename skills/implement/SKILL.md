# Implement

Read [workflow](../workflow/SKILL.md). Resolve the selected change and any supplied Linear issue, including its comments and linked OpenSpec tasks. Read the current specification and design rather than assuming the original issue brief remains current.

Use [openspec-apply-change](../openspec-apply-change/SKILL.md) for the task loop and [tdd](../tdd/SKILL.md) for behavioral implementation. Select only the requested task scope; shared prerequisites must be complete. Read project conventions before editing.

Prove each completed behavior and review the full relevant changes with [code-review](../code-review/SKILL.md). Record evidence in the change, mark only completed tasks, and post a concise relevant result on linked issues. Commit or publish only under the user's authorization and project policy.
