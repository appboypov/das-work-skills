# Clarify with project context

Read [workflow](../workflow/SKILL.md), [grilling](../grilling/SKILL.md) and [domain-modeling](../domain-modeling/SKILL.md).

Read the existing change and relevant source before asking. Use the questioning method to settle the current decision frontier. Record agreed terms in the domain glossary and significant decisions in their owning change or ADR. Keep proposed behavior distinct from observed behavior. Finish with the agreed outcome, remaining blockers and links to recorded decisions. Implementation waits for its approved scope.
